# Classroom link forwarding

Learning Room is now maintained by KERN Design Studio:

- [Application source](https://github.com/KernDesignStudio/learning-room-platform)
- [Live demonstration](https://kerndesignstudio.github.io/learning-room-platform/#/)

This small GitHub Pages site keeps the original classroom QR link working. The `/learning-room-platform/` page forwards visitors to the KDS demonstration, preserving the requested hash route. It does not copy browser storage, workspace tokens or query parameters.

The application source and its development instructions are in the KDS repository. This repository contains only the forwarding page.
